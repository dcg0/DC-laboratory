¿Qué hace cada pieza?

ESP32 + adaptador ELM327

Ilustraciones genéricas: el modelo y la apariencia del hardware pueden variar.

ESP32 · ejecuta el firmware

Es el microcontrolador que corre el sketch y aloja el panel web en su propia red Wi-Fi local. El teléfono se conecta a esa red para abrir la interfaz del dispositivo.

La placa exacta compatible depende del hardware y la compilación del proyecto.

ELM327 Bluetooth · enlace OBD-II

Se conecta al puerto OBD-II del vehículo y actúa como interfaz para las consultas compatibles que envía el firmware, como PIDs, códigos DTC y VIN.

La compatibilidad varía entre adaptadores ELM327 y vehículos; la imagen es ilustrativa, no una recomendación de compra.

Para ver esta página

Solo necesitas el navegador. Todo dato y acción de la demo se genera localmente; no se hacen solicitudes al ESP32.

Para usar el programa real

Necesitas una placa ESP32 compatible, un adaptador ELM327 Bluetooth compatible y un vehículo con puerto OBD-II. Descarga el ZIP del repo y sigue el README: requiere Arduino ESP32 core 2.0.17 y partición Huge APP.
