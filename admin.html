Acompañamiento / Instalación

Instalación sin vueltas.

La forma recomendada para oficina es ejecutar el instalador Docker una sola vez en una computadora o servidor con Docker Desktop. El asistente crea la carpeta, genera credenciales seguras, levanta la base de datos y abre el sistema en el navegador.
